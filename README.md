# CPSC581 Project 3

Thanksgiving Moderator is a simple device that is intended to provide a simple solution to distracting political talk during family dinners.

It listens to your conversations, watching for political speak or profanity. If the conversation goes in that direction, it respectfully redirects the discussion
through various modalities of output.

It augments a traditional speaker system. For voice isolation (i.e. filtering out music), as well as to pass its own voice out, it must be connected to a speaker.
In our demo implementation, we handle processing, recording, and playback through a connected laptop.

## How to Run

### Install
1. Clone the repository
> git clone https://github.com/emickelson1/cpsc581p3.git
2. Download the [model](https://alphacephei.com/vosk/models/vosk-model-en-us-0.22-lgraph.zip) (see Voice Recognition below for more details)
3. Unzip the model, move it to the project directory, and rename it as `model`
4. Install the dependencies:

## Voice Recognition

Using Vosk Speech Recognition Toolkit: https://github.com/alphacep/vosk-api/tree/master

Model download: https://alphacephei.com/vosk/models > [vosk-model-en-us-0.22-lgraph](https://alphacephei.com/vosk/models/vosk-model-en-us-0.22-lgraph.zip) (128 MB)

After cloning the project, download the model above, then rename the model folder to `model` and place it in this project's directory
